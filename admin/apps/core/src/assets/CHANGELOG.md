# 关于本管理后台

**HOAI**（**HubOpenAI** 简称）管理控制台用于运营与配置当前站点：用户与访问、模型与对话、支付与套餐、存储与安全策略等。页面数据与保存能力由 **本仓库后端 API** 提供。

**源码仓库**：[github.com/hubopenaicom/HOAI](https://github.com/hubopenaicom/HOAI)

## 技术说明

前端界面基于开源后台脚手架 **[Fantastic-admin](https://github.com/fantastic-admin/basic)**（Vue 3、Vite、Element Plus 等）定制开发，遵循其 **MIT** 许可。若需了解脚手架本身，可参考其 [文档](https://fantastic-admin.hurui.me) 与 [Releases](https://github.com/fantastic-admin/basic/releases)。

业务逻辑、接口与数据归属以当前部署的 **本项目后端** 为准；版本与能力说明以本仓库文档与发行记录为准。使用与分发时请同时遵守各依赖及后端项目自身的许可条款。
